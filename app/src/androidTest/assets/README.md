# Local-only speech fixture

`offline-preview-test.wav` is a retained local fixture used by the historical
Preview 3 release instrumentation. It is intentionally excluded from the source
publication until its original generation/licensing evidence is reconciled.
No personal recording is being asserted or redistributed here.

Historical observations remain recorded; a clean checkout does not include this
fixture and therefore cannot replay that retired instrumentation without a
separately supplied, authorized matching fixture. This does not affect the normal
application build or unit tests. Future non-bundled releases must use newly
provenanced test inputs and their own acceptance results.
